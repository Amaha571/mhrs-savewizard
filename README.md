# mhrs-savewizard

曙光 PS4 存档工坊网页版（1.0.0）。

支持导入 Save Wizard 导出的角色文件，编辑装备、怪异炼化、护石、道具、装饰品、金钱与炎火点数，再下载修改副本。

存档在浏览器内处理，不会上传到服务器。请自行保留原始存档备份。

## GitHub Pages 发布

创建公开仓库 `mhrs-savewizard`，将本压缩包解压后的文件上传至仓库根目录。
在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。
发布后地址为 `https://你的GitHub用户名.github.io/mhrs-savewizard/`。

网页文件与现有网页版一致，没有加入角色存档、缓存或托管账号配置。
